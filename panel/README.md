# KiCad PCB Panel Template

A KiCad PCB template for decorative panels. Adjust it according to your needs.

## Layer usage

- **Visible metal:** copper on a layer + a mask layer to expose it.
- **Texture / bump:** copper without a mask layer exposing it.
- **Silk screen:** applied on top of a solder mask layer.

## Manufacturing

These panels are manufactured at JLCPCB. To get a similar finish to mine, order with:

- ENIG finish
- Edge plating
- Black soldermask
- Standard FR4 and thickness

Include this note in the order comments:

> Please plate all holes and all drills. Plate all edges as indicated by F.cu boxes. Four areas are left for tooling handles.
